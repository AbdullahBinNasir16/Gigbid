# Content recommendation engine

## The problem
The client, a media company, had a problem: a news site showed the same trending list to everyone.

## What I built
I built a two-tower recommendation model with daily retraining. The stack was Recommender Systems, PyTorch, Python, SQL and Machine Learning.

## Result
The work click-through rate rose 17% in an A/B test.
