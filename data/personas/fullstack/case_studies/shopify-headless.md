# Headless Shopify storefront

## The problem
The client, a e-commerce company, had a problem: a fashion brand's theme scored 28 on mobile Lighthouse.

## What I built
I built a headless storefront on the Shopify Storefront API with image optimisation. The stack was Shopify, Next.js, GraphQL, React and Vercel.

## Result
The work Lighthouse mobile went from 28 to 94 and conversion rose 22%.
