# AI chat widget for a SaaS site

## The problem
The client, a saas company, had a problem: visitors left the pricing page with unanswered questions.

## What I built
I built an embeddable chat widget that answers from the docs and books demos. The stack was React, Node.js, OpenAI API, TypeScript and Vercel.

## Result
The work demo bookings from the site rose 18%.
