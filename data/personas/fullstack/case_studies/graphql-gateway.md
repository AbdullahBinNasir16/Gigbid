# GraphQL API gateway

## The problem
The client, a media company, had a problem: mobile clients made 14 REST calls to render one screen.

## What I built
I built an Apollo federation gateway over five services with response caching. The stack was GraphQL, Node.js, Apollo, Redis and Microservices.

## Result
The work screen load time dropped from 2.8 s to 0.9 s.
