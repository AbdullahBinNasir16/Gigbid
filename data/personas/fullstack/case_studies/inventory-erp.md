# Inventory module for a small ERP

## The problem
The client, a wholesale company, had a problem: a wholesaler tracked stock in Excel across three warehouses.

## What I built
I built an inventory module with transfers, barcode scanning and low-stock alerts. The stack was Django, Python, PostgreSQL, REST API and Bootstrap.

## Result
The work stock-count discrepancies fell from 9% to 1.5%.
