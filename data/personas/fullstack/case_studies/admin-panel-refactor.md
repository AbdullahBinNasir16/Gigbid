# Legacy admin panel modernisation

## The problem
The client, a insurance company, had a problem: a jQuery admin panel broke on every release.

## What I built
I built a typed React rewrite behind a feature flag with 80% test coverage. The stack was React, TypeScript, REST API, Jest and Testing.

## Result
The work release regressions went from about 6 per month to 1.
