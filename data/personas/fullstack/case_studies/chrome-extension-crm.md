# CRM browser extension

## The problem
The client, a sales company, had a problem: sales reps copied contact details into the CRM by hand.

## What I built
I built a browser extension that logs emails and meetings to HubSpot with one click. The stack was JavaScript, Chrome Extension, REST API, HubSpot API and TypeScript.

## Result
The work saved reps about 3 hours a week each.
