## Rules applied

* Dropped rows whose description is missing or shorter than 60 characters.
* Dropped duplicate job URLs (query string removed), then exact duplicates of normalised title plus description, then near duplicates (same normalised title and the same first 300 normalised description characters). The 60k set is loaded first, so its richer rows win ties.
* Budgets outside the configured ranges were set to null (row kept).
* Emails, URLs, phone numbers (9 to 15 digits) and messenger handles were replaced with [EMAIL], [URL], [PHONE] and [HANDLE].
* Category comes from the weighted keyword rules in data/real/taxonomy.yaml.
* Skills: the 60k set's own skill tags; for the 50k set, vocabulary skills found in the title and description.
